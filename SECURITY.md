# Security

Vulnerabilities in the code itself belong upstream:

- MongoDB C Driver: [create a vulnerability report](https://www.mongodb.com/docs/manual/tutorial/create-a-vulnerability-report/)
- OpenSSL: [reporting security bugs](https://openssl-library.org/community/#reporting-security-bugs)

For a problem with the binaries or the build published here, such as a download that fails verification or a DLL with an unexpected dependency, please [report it privately](https://github.com/jamalofski/libmongoc-binaries/security/advisories/new) rather than in a public issue.

The OpenSSL version inside each package is listed in its release notes and in the DLL file properties.
